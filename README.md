# Operação ARQCOMP

Jogos de revisão de Arquitetura Computacional para a Sprint 3 da SPTech. O site usa HTML, CSS e JavaScript e guarda os recordes de XP no navegador.

[Versão para jogar](https://operacao-arqcomp.transparentoasis3.chatgpt.site)

## Como jogar

- **Cruzadinha** — Selecione uma pista horizontal ou vertical e digite nas casas do tabuleiro. Use **Conferir** para ver os acertos, erros e palavras incompletas. Use **Reiniciar** para limpar a grade.
- **Quiz tático** — Responda às 12 perguntas. Leia a explicação antes de avançar.
- **Jogo da memória** — Vire duas cartas por vez até encontrar os oito pares de termos e definições.
- **Ordem de execução** — Mova as etapas para cima ou para baixo e confira cada uma das quatro sequências.

## Palavras e pistas

| Palavra no tabuleiro | Direção | Pista |
| --- | --- | --- |
| QUADCORE | Horizontal | Classificação de um processador que tem exatamente quatro núcleos. |
| RAM | Vertical | Área de trabalho volátil que guarda programas e dados em uso. |
| ULA | Vertical | Parte da CPU que faz somas, subtrações e operações como AND. |
| UC | Horizontal | Parte da CPU que interpreta instruções e comanda os demais circuitos. |
| MEMORIADEMASSA | Horizontal | Categoria à qual pertencem SSDs e HDs usados para guardar arquivos. |
| DMA | Vertical | Recurso que move blocos entre periféricos e RAM sem cópia manual pelo processador. |
| EEPROM | Vertical | Tecnologia não volátil do Uno usada para guardar pequenas configurações alteráveis byte a byte. |
| ROM | Vertical | Tipo clássico que guarda conteúdo fixo, normalmente gravado na fabricação. |
| REGISTRADORES | Horizontal | Pequenos espaços internos do processador que guardam operandos e resultados imediatos. |
| DATABUS | Vertical | Nome em inglês do caminho que leva os valores trocados entre componentes. |
| MICROCONTROLADOR | Horizontal | Tipo de chip do Arduino Uno que reúne núcleo, armazenamento interno e periféricos. |
| DUALCORE | Vertical | Classificação de um processador que tem exatamente dois núcleos. |
| ADDRESSBUS | Horizontal | Nome em inglês do caminho que indica qual posição será acessada. |
| FLASH | Horizontal | Tecnologia não volátil apagada em blocos que guarda o programa no Arduino Uno. |
| CACHE | Horizontal | Área rápida que mantém cópias de informações usadas recentemente ou com frequência. |
| CPU | Vertical | Bloco do computador que busca e executa as instruções de um programa. |

## Abrir e publicar

Extraia todos os arquivos para a mesma pasta e abra `index.html` no navegador.

Para a entrega, publique a raiz do projeto pelo GitHub Pages no repositório público `arqcomp-cruzadinha`. Em **Settings → Pages**, selecione **Deploy from a branch**, a branch `main` e a pasta `/ (root)`. Depois de publicar, atualize o link deste README e teste o novo endereço numa janela anônima. A atividade pede ao menos seis commits ao longo do desenvolvimento em dois dias diferentes e apenas o link do GitHub Pages no Moodle.
